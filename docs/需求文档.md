# 学生选课管理系统 - 需求与设计文档

## 1. 项目概述
- **选题**：学生选课管理系统
- **目标用户**：学生、教师、教务管理人员、系统管理人员
- **核心流程**：多角色登录 -> 课程/选课管理 -> 成绩与课表展示 -> 后台数据与权限维护

## 2. 功能需求

### 2.1 学生模块
 功能点  详细描述 

 登录/登出  使用学号+密码登录，支持密码修改 
 课程查询  按课程名、教师、院系、时间等条件筛选课程 
 选课  在选课开放期内选择课程，自动检测时间冲突和课程容量 
 退课  在退课截止前取消已选课程 
 我的课表  查看本学期个人课表（周视图/列表视图） 
 成绩查询  查看已修课程成绩 
 学分进度  查看已修学分及各类型学分（必修/选修）完成情况 

### 2.2 教师模块
 功能点  详细描述 

 登录/登出  使用工号+密码登录 
 我的课程  查看本学期授课课程列表 
 学生名单  查看选课学生信息（姓名、学号） 
 成绩录入  录入/修改学生成绩，支持 Excel 批量导入 
 课程信息维护  修改课程简介、大纲、上课地点等 

### 2.3 教务管理员模块
 功能点  详细描述 

 课程管理  新增/编辑/删除课程，设置学分、容量、上课时间 
 排课管理  分配教室、时间段，检测教室冲突 
 选课规则设置  设置选课开放时间、退课截止时间、选课上限 
 学生管理  导入/编辑学生信息，支持批量导入 
 教师管理  导入/编辑教师信息 
 数据统计  生成选课人数统计、课程热度报表 
 异常处理  手动调整学生选课记录（如补选/退选） 

### 2.4 系统管理员模块
 功能点 | 详细描述 

 角色权限管理  分配各角色的操作权限 
 账号管理  重置密码、冻结账号 
 数据备份与恢复  定期备份数据库，支持恢复 
 日志审计  记录关键操作日志（选课、成绩修改等） 

## 3. 非功能需求

### 3.1 性能需求
系统支持并发用户数 ≥ 500
选课操作响应时间 < 2 秒
页面加载时间 < 3 秒

### 3.2 安全性需求
密码加密存储（如 Bcrypt）
防止 SQL 注入、XSS 攻击
关键操作需二次确认
会话超时自动登出

### 3.3 可用性与兼容性
界面简洁直观，支持主流浏览器（Chrome、Firefox、Edge 最新版）
关键操作有成功/失败提示，提供操作帮助文档
后端支持主流操作系统

## 4. 数据库设计（核心实体与数据量）

### 4.1 核心实体
 实体  主要属性 

 学生  学号、姓名、院系、专业、年级、密码 
 教师  工号、姓名、院系、职称、密码 
 课程  课程号、课程名、学分、容量、上课时间、教室、教师 
 选课记录 学号、课程号、选课时间、成绩 
 院系/专业  院系编号、名称、专业列表 

### 4.2 数据量估算
数据类型  估算量 

学生  约 5000 人 
教师  约 500 人 
课程  约 800 门学期 
选课记录 约 30000 条学期
